# Novacore

Navacore is a sleek gaming website delivering the latest news, reviews, and guides. Built for casual and competitive players alike, it’s a hub where gamers stay informed, connected, and inspired.

## Features
- Latest game news & release coverage
- Concise reviews and rating system
- Strategy guides and how-to articles
- Community hub: forums/comments/user profiles
- Responsive, modern UI with fast load times

## Tech / Stack (example)
- HTML, CSS (Tailwind), JavaScript (React)
- Backend: Node.js / Express or Next.js API routes
- Database: PostgreSQL or MongoDB
- Auth: OAuth (Discord/Steam) or email/password
- Hosting: Vercel / Netlify / DigitalOcean
